# Protoptera Player

Крошечный плеер под Windows для **mp3, flac и wav** в фирменном стиле Protoptera (чернила `#0A0A09` / янтарь `#FFAA1D` / кость `#F4F1E8`, когти и ледоруб). Заголовок трека, плашка формата с параметрами потока (`96 kHz · 24 bit`), **вшитая обложка** (если есть в тегах), полоса перемотки, кнопки **Play/Pause** и **Stop**, кнопка «поверх всех окон». Одно окно на всё: клик по другому файлу запускает его **вместо** текущего, а не плодит окна.

- Нативный WPF. Проигрывание — встроенный `MediaPlayer` (FLAC декодирует Media Foundation, есть в Windows 10/11 из коробки), теги и обложка — `TagLibSharp` (бандлится внутрь exe, итог — один файл).
- Один процесс (single-instance) через `Mutex` + named pipe.
- Ставится в один клик, регистрируется в «Установленных приложениях», удаляется штатно.

## Установка / обновление (в один клик)

1. Поставь **.NET 8 SDK** (если ещё нет): `winget install Microsoft.DotNet.SDK.8` (или https://dotnet.microsoft.com/download/dotnet/8.0). После установки открой всё заново.
2. Распакуй архив (ПКМ по zip → «Извлечь всё»).
3. Дважды кликни **`setup.cmd`**. Он сам соберёт, установит/обновит и запустит плеер.
4. Один раз назначь по умолчанию — для каждого формата (`.mp3`, `.flac`, `.wav`): ПКМ по файлу → «Открыть с помощью» → «Выбрать другое приложение» → **Protoptera Player** → галочка «Всегда».

`setup.cmd` работает и как **апдейтер**: гасит запущенный плеер, пересобирает, перезаписывает установленную версию и подчищает прошлую (в т.ч. старую MiniMp3).

> После обновления с переименованием назначение по умолчанию слетает — Windows привязывает дефолт к конкретному приложению (защита UserChoice). Переназначь один раз (шаг 4). Это единственное ручное действие.

---

## Удаление

Штатно: **Параметры → Приложения → Установленные приложения → Protoptera Player → Удалить**.
Либо запусти `uninstall.cmd` из папки `%LOCALAPPDATA%\ProtopteraPlayer`.

Удаление сносит папку установки, ассоциации с .mp3/.flac/.wav и запись в списке приложений.

## Как пользоваться

- Двойной клик по mp3/flac/wav в проводнике → играет в Protoptera Player.
- Клик по другому файлу, пока плеер открыт → новый трек играет **вместо** старого, окно не дублируется.
- **Обложка** из тегов (ID3 APIC у mp3/wav, PICTURE у flac) показывается слева; если её нет — фирменный плейсхолдер: узор «когти» + ледоруб.
- Можно **перетащить** mp3/flac/wav прямо на окно.
- **Пробел** — Play/Pause.
- Кнопка-«кнопка» (точка с иглой) в шапке — **поверх всех окон**; активна = янтарная.
- По полосе прогресса можно кликать и тащить для перемотки.
- Окно перетаскивается за шапку.

## Что осознанно НЕ реализовано

Плейлистов, эквалайзера, редактирования тегов, громкости в окне — нет (громкость крути системным микшером). Цель — базовый минимум.

## Кастомизация

- **Иконка:** `Assets/icon.ico` (собрана из бренд-пака: ледоруб с когтями в круге, для 16–24 px — упрощённые когти). Хочешь другую — замени файл.
- **Графика:** `Assets/*.png` — глифы и тайл узора из бренд-пака, вшиваются в exe.
- **Размер обложки/цвета/габариты окна:** правь `MainWindow.xaml` (палитра бренда — в `Window.Resources` сверху, обложка — блок «Обложка», размер квадрата `Width/Height="128"`).
- **Стартовать уже закреплённым поверх окон:** в `MainWindow.xaml.cs` в конце конструктора добавь `PinButton_Click(this, null);`.

## Структура

    ProtopteraPlayer.csproj   — проект (+ ссылка на TagLibSharp)
    App.xaml / .cs            — запуск + single-instance
    MainWindow.xaml / .cs     — интерфейс, проигрывание, обложка
    Assets/                   — иконка и графика бренд-пака
    setup.cmd / setup.ps1     — сборка + установка/обновление + регистрация
    uninstall.cmd / .ps1      — штатное удаление
